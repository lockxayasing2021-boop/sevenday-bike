📋 ทำไมต้อง Bridge Layer?
Sevenday ERP ทำงานบน Google Apps Script (GAS) ซึ่ง expose endpoint เป็น Web App URL โดยตรง แต่ Website ไม่ควรเรียก GAS ตรงเพราะ: (1) ไม่มี Auth layer, (2) CORS ไม่ยืดหยุ่น, (3) Rate limit ของ Google, (4) ยากต่อการ version ในอนาคต. Bridge Layer แก้ทั้ง 4 ข้อนี้

Deployment Options (เลือกตามงบและ tech stack)

☁️ Option A — GAS Direct

ใช้ GAS Web App เป็น API โดยตรง เพิ่ม doGet/doPost ใน Sevenday ERP ที่มีอยู่แล้ว เหมาะกับช่วงแรก ต้นทุนศูนย์

// ใน Code.gs ของ ERP function doGet(e) { const action = e.parameter.action; return handleGet(action, e); }
⚡ Option B — Cloudflare Workers

Proxy ผ่าน Cloudflare Workers (Free tier) ได้ Auth, CORS, Rate limit โดยไม่มี Server — แนะนำสำหรับ Sevenday

// worker.js export default { async fetch(req, env) { // Auth → Proxy to GAS return proxyToGAS(req); } }
🐍 Option C — Python/Node

Server จริง (VPS/Railway/Render) มีความยืดหยุ่นสูงสุด เหมาะเมื่อระบบเติบโตและต้องการ database แยก

§ 3 · Authentication

Auth & Security

สองระดับ — Public สำหรับ Browse, Authenticated สำหรับ Order/Account

🔑 API Key (Server → Server)

ใช้สำหรับ Admin Panel และ GAS Bridge เรียก API โดยตรง ส่งใน Header ทุก request

// Request Header X-API-Key: sk_live_sevenday_xxxx Content-Type: application/json
🎫 JWT Token (Customer Session)

ลูกค้า Login ผ่าน /auth/login ได้ JWT Token อายุ 7 วัน ส่งใน Authorization header

// Authorization Header Authorization: Bearer eyJhbGci... // JWT Payload { "sub": "CUST-2024-001", "phone": "020XXXXXXXX", "exp": 1735689600 }
🌐 Public Endpoints (No Auth)

Products, Categories, Store Info, Service Packages — ใครก็เรียกได้ ไม่ต้องใช้ Auth

// Public — ไม่ต้องส่ง Header GET /v1/products GET /v1/products/:id GET /v1/categories GET /v1/services GET /v1/store/info
🔒 Protected Endpoints

Orders, Cart, Account, Bookings — ต้องมี JWT. Admin endpoints ต้องมี API Key + Admin role

// Protected — ต้องมี JWT POST /v1/orders GET /v1/account/orders POST /v1/bookings // Admin — ต้องมี API Key GET /v1/admin/orders PUT /v1/admin/products/:id
⚠ GAS Web App Security: GAS Web App URL เป็น "Anyone" by default — ต้องตรวจสอบ custom secret key ใน GAS ด้วยตัวเอง (Bridge ส่ง X-GAS-Secret Header ทุก request, GAS ตรวจก่อน process)

§ 6 · Sync Strategy

Data Sync Strategy

อะไรควร sync ทิศทางไหน และ trigger เมื่อไหร่

DataทิศทางTriggerFrequencyหมายเหตุ
Products / Prices ← ERP → Web ⏰ Scheduled ทุก 15 นาที + Manual Cache บน Website, ERP เป็น source of truth
Stock / Inventory ← ERP → Web ⚡ Real-time ทุก checkout + On-demand ต้องตรวจ real-time ก่อน confirm Order
New Orders Web → ERP → ⚡ On Event ทันทีที่ลูกค้า checkout Web push → GAS เขียน Sheets → POS รับงาน
Order Status ← ERP → Web ⏰ Scheduled ทุก 5 นาที POS อัพเดตสถานะ → Website แสดงผล
Service Bookings ↔ Both ⚡ On Event ทันทีที่จอง / Confirm Web สร้าง Booking → ERP Confirm → Web แสดง status
Customers / CRM ↔ Both ⚡ On Event เมื่อมี New Order / ลงทะเบียน Upsert — ถ้า phone มีแล้วใน CRM ให้ update แทน insert
Loyalty Points ← ERP → Web ⏰ Scheduled ทุก 1 ชม. คำนวณใน ERP/POS ส่งกลับมาแสดงบน Account page
Film Requests Web → ERP → ⚡ On Submit ทันทีที่ Submit form บันทึกลง Bookings Sheet ประเภท "film"
⚠ GAS Date Serialization Bug: ระวัง Date object ใน Apps Script ที่แปลงเป็น string — ใช้ new Date(value).toISOString() เสมอ และตรวจสอบ timezone offset (+07:00 สำหรับ Vientiane) ก่อน write ลง Sheets
§ 7 · ERP Bridge

GAS Bridge Implementation

โค้ด template สำหรับเพิ่มใน Sevenday ERP (Code.gs)

📄 Router Pattern (เพิ่มใน Code.gs)
/** * Sevenday ERP — Web API Bridge * เพิ่มไฟล์นี้ในโปรเจกต์ GAS ของ Sevenday ERP */ const GAS_SECRET = PropertiesService .getScriptProperties().getProperty('WEB_API_SECRET'); function doGet(e) { if (!verifySecret(e)) return err(401, 'Unauthorized'); const action = e.parameter.action; switch(action) { case 'getProducts': return getProducts(e.parameter); case 'getProduct': return getProduct(e.parameter.id); case 'getSlots': return getAvailableSlots(e.parameter.date); case 'getCustomer': return getCustomer(e.parameter.phone); default: return err(400, 'Unknown action'); } } function doPost(e) { if (!verifySecret(e)) return err(401, 'Unauthorized'); const body = JSON.parse(e.postData.contents); const action = body.action; switch(action) { case 'createOrder': return createOrder(body); case 'createBooking': return createBooking(body); case 'upsertCustomer':return upsertCustomer(body); case 'filmRequest': return createFilmRequest(body); default: return err(400, 'Unknown action'); } } // Verify shared secret from Bridge layer function verifySecret(e) { const secret = (e.parameter.secret) || (e.postData ? JSON.parse(e.postData.contents).secret : null); return secret === GAS_SECRET; } // Helper: return JSON response function ok(data) { return ContentService .createTextOutput(JSON.stringify({ ok: true, data })) .setMimeType(ContentService.MimeType.JSON); } function err(code, msg) { return ContentService .createTextOutput(JSON.stringify({ ok: false, error: msg, code })) .setMimeType(ContentService.MimeType.JSON); } // ── createOrder ────────────────────────── function createOrder(body) { const sheet = SpreadsheetApp .openById(SHEET_ID).getSheetByName('Orders'); const orderId = generateOrderId(); // SD-2024-NNNN sheet.appendRow([ orderId, body.customer.name, body.customer.phone, JSON.stringify(body.items), // ⚠ stringify ก่อนเสมอ body.subtotal_lak, body.discount_lak || 0, body.total_lak, body.currency, body.delivery_method, body.payment_method, 'pending', 'website', // source new Date().toISOString() // ⚠ ใช้ ISO ป้องกัน date bug ]); return ok({ order_id: orderId, status: 'pending' }); }
✓ Deploy Steps สำหรับ Sevenday ERP:
1. เปิดโปรเจกต์ ERP ใน Apps Script Editor (หรือผ่าน clasp)
2. สร้างไฟล์ใหม่ชื่อ WebApiRouter.gs — วางโค้ด Router ด้านบน
3. Script Properties → เพิ่ม WEB_API_SECRET=your_secret_here
4. Deploy → New Deployment → Web App → Execute as Me → Anyone
5. Copy Web App URL → ใส่ใน Cloudflare Worker / Bridge config
§ 8 · Roadmap

Integration Roadmap

ลำดับการ Integrate ที่แนะนำ — เริ่มจากง่ายที่สุดก่อน

Phase 1 — เดือน 1
🔌 GAS Bridge พื้นฐาน
  • เพิ่ม WebApiRouter.gs ใน Sevenday ERP
  • Deploy GAS Web App + set Secret
  • Cloudflare Worker proxy พื้นฐาน
  • GET /v1/products จาก Sheets
  • POST /v1/orders → เขียน Orders sheet
  • POST /v1/bookings → เขียน Bookings sheet
Phase 2 — เดือน 2
🔐 Auth & Customer
  • Phone OTP Login (Twilio/Firebase)
  • JWT token issue + verify
  • GET /v1/account endpoints
  • Customer upsert → CRM Sheet
  • Loyalty points sync
Phase 3 — เดือน 3
⚡ Real-time Stock & Status
  • Inventory check ก่อน checkout
  • Order status polling (5 นาที)
  • Low stock alert → Admin
  • Admin API endpoints
  • Rate limiting + caching layer
Phase 4 — อนาคต
🚀 Advanced Features
  • LINE Notify Order status
  • Payment gateway (BCEL Online)
  • Search index (Algolia/MeiliSearch)
  • Analytics → Sheets dashboard
  • Multi-branch support (ถ้าขยาย)
📋 เริ่ม Phase 1 ได้เลยเพราะ: Sevenday ERP (clasp + GAS) พร้อมแล้ว — แค่เพิ่ม WebApiRouter.gs ไฟล์เดียวก็ expose API ได้ทันที ไม่ต้องสร้าง Backend ใหม่ และ Cloudflare Workers Free tier รับ 100,000 requests/วัน เพียงพอสำหรับ Sevenday ในช่วงแรก
